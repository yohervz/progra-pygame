# Plantilla Base: Juego de Plataformas 2D en Pygame

¡Bienvenido/a a la base de tu nuevo juego de plataformas!

Para consultar la guía paso a paso y aprender cómo diseñar tus propios niveles y personajes, lee [platformer/README.md](platformer/README.md).

## Cómo Ejecutar tu Juego

```bash
# Con uv:
uv run python platformer/main.py

# O con python tradicional:
python platformer/main.py
```

## Pruebas de Funcionamiento

```bash
uv run python platformer/tests/test_platformer.py
```
