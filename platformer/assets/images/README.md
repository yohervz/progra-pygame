# Carpeta de Imágenes y Sprites

¡Aquí puedes colocar tus propios dibujos, sprites e ilustraciones personalizadas!

Archivos que puedes añadir:
- `player.png`: Tu personaje principal (recomendado 32x48 o 32x32 píxeles con fondo transparente PNG).
- `enemy.png`: Tu enemigo patrullero (recomendado 32x32 píxeles PNG).
- `platform.png`: Textura para tus bloques de plataformas (recomendado 40x40 píxeles PNG).
- `background.png`: Imagen de fondo para el cielo o escenario (ejemplo 800x600 píxeles). Si no colocas esta imagen, se usará el color `COLOR_BACKGROUND` de `settings.py`.

> **Consejo para ti:** Si todavía no tienes tus imágenes terminadas, ¡no te preocupes! El juego cuenta con **sprites de respaldo automáticos** que dibujarán a tus personajes y bloques geométricamente con ojos y colores para que puedas concentrarte en programar sin esperar al arte final.
